# Flet MIDI 播放器

一个使用Flet框架开发的功能完整的MIDI播放器，支持实时琴键显示和琴卷可视化。

## 功能特性

### 核心功能
- ✅ **MIDI文件加载**: 支持 .mid 和 .midi 格式文件
- ✅ **播放控制**: 播放、暂停、停止、进度跳转
- ✅ **实时琴键显示**: 88键钢琴键盘可视化，活动音符高亮显示
- ✅ **琴卷可视化**: 展示所有音符的时间线和频率分布
- ✅ **音符信息**: 实时显示当前播放的音符名称
- ✅ **进度控制**: 滑块进度条和时间显示

## 使用方法

### 运行应用
```bash
python midiplayer.py
```

### 基本操作
1. **打开MIDI文件**: 点击"打开MIDI文件"按钮，选择.mid或.midi文件
2. **播放**: 点击▶️按钮开始播放
3. **暂停**: 点击⏸️按钮暂停播放
4. **停止**: 点击⏹️按钮停止播放并重置到起点
5. **跳转**: 拖动进度条到任意位置
6. **查看琴键**: 观察琴键可视化器显示当前活动的琴键（红色高亮）
7. **查看琴卷**: 琴卷显示所有音符的时间-频率分布

## 组件说明

### MidiPlayer (核心播放引擎)
- **加载MIDI**: `load_midi(file_path)` - 解析MIDI文件
- **播放控制**: `play()`, `pause()`, `resume()`, `stop()`
- **跳转**: `seek(time)` - 跳转到指定时间
- **音符解析**: 自动提取所有音符数据
- **活跃音符追踪**: 实时计算当前时间的活跃音符

### KeyboardVisualizer (钢琴键盘)
- 88键标准钢琴布局
- 白键和黑键正确显示
- 活跃音符用红色高亮

### PianoRoll (琴卷)
- 横轴表示时间
- 纵轴表示音符频率
- 矩形表示音符（宽度=音符持续时间）
- 蓝色表示已加载的音符，活跃音符会改变显示

## 键盘快捷键（可扩展）

建议添加：
- `Space`: 播放/暂停
- `←/→`: 后退/前进 5秒
- `Ctrl+O`: 打开文件
- `Ctrl+S`: 另存琴卷图像

## 故障排除

### 问题: "加载MIDI失败"
- 检查文件是否存在和有效
- 确保MIDI文件不损坏

### 问题: 没有声音输出
- 目前版本通过mido只读取MIDI信息
- 如需音频输出，需要集成音频合成库

### 问题: 琴键显示位置不正确
- 这是Flet CustomPaint的布局问题
- 可能需要调整Canvas尺寸

## 文件大小限制

当前版本支持的MIDI文件大小: 理论无限制  
实际限制取决于系统内存和UI渲染性能
